# LabTrace User Stories

## Technicians
- [] As a technician, I want to register a new sample
- [] As a technician, I want to transition samples to the next stage
- [] As a technician, I want to view a sample's details and processing history so that I can understand its current state.

## Reviewer
- [] As a reviewer, I want to search for and locate a sample
- [] As a reviwer, I want to record quality control findings
- [] As a reviewer, I want to resolve or close a quality control finding so that corrected issues no longer appear as outstanding.

## Administrator
- [] As an administrator, I want to see a sample's audit history
- [] As an administrator, I want to quickly understand exceptions and statuses for samples
- [] As an administrator, I want to be able to see outstanding quality control issues, samples requiring attention, and see sample counts by status

## System
- [] As a system, I must reject invalid sample transitions and record significant changes so that sample integrity and traceability are maintained.
